# RS React Class Components

React application for RS School React course Task 1: Class Components.

## Tech stack

- React
- TypeScript
- Vite
- pnpm
- ESLint
- Prettier

## Scripts

Install dependencies:

```bash
pnpm install
```

Run development server:
```bash
pnpm dev
```

Build project:
```bash
pnpm build
```

Run linter:
```bash
pnpm lint
```
